# MediaMate — User & Media Management System

MediaMate is a responsive web application built with HTML5, CSS3, JavaScript, and Bootstrap.

It combines user authentication, contact management, video management, playlists, and a custom video player in one application.

## Features

### Authentication
- Sign Up
- Login
- Logout
- Cookie and session handling
- Protected user sections

### Contact Management
- Add contacts
- View contacts
- Delete contacts
- User-specific contacts

### Video & Playlist Management
- Add videos
- Delete videos
- Create and manage playlists
- User-specific videos and playlists

### Custom Video Player
- Play / Pause
- Next video
- Volume control
- Playback speed
- Full-screen mode
- Playlist support

## Problem Solved

MediaMate keeps each user's contacts, videos, and playlists separate so users cannot normally access another user's data through the application.

It also provides a login and signup system to control access to user-specific sections.

## Backend

This version does not require a backend or database. It uses browser-side technologies such as Cookies, Sessions, and Local Storage to manage user and application data.
